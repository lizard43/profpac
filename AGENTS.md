READ [ENGINEERING-RULES.md](ENGINEERING-RULES.md) before editing. Original source, language, TERSE loader/interpreter, DNA XC and runtime are the authority. Load whole original-style programs through the original tools. Host scripts are for orchestration, packaging and independent verification ONLY. Hardware-specific native assembly requires explicit, traceable justification. If the original mechanism is blocked, STOP, explain and request approval **before** changing approach. Consult docs/SPRINT-PLAN.md and docs/TECHNICAL-DEBT.md; preserve existing work. Never claim unexecuted builds/tests. Passing tests is no exemption.
